# Design System

1. Em projeto novo: alinhar direção com o usuário antes de fixar tokens.
2. Em existente: estender o sistema atual — não criar paralelo.
3. Tokens: cor, tipo, espaço, raio, elevação com nomes estáveis.
4. Componentes com estados reais (hover/focus/disabled/loading/error).
5. Proibir texto decorativo e padrões genéricos de “AI slop” visual.
