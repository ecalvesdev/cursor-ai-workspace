# Responsive Layout

1. Mobile-first; validar larguras pequenas e grandes.
2. Hierarquia tipográfica e espaçamento consistentes com o design system.
3. Áreas de toque adequadas; evitar overflow horizontal.
4. Imagens/fluidos com limites; não quebrar container.
5. Preferir CSS do projeto (Tailwind/tokens) a valores mágicos repetidos.
