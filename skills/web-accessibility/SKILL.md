# Web Accessibility

1. HTML semântico antes de ARIA.
2. Fluxos usáveis por teclado; foco visível.
3. Labels/erros associados em formulários.
4. Imagens informativas com alt; decorativas ignoradas.
5. Não comunicar estado só por cor.
6. Contraste adequado nos tokens do tema.
