# E2E Testing

1. Cobrir jornadas críticas, não tudo.
2. Seletores estáveis; dados de teste isolados.
3. Assertions de comportamento observável.
4. Evidência em falha; retries limitados só se seguros.
5. Não usar E2E para substituir unitário de regra pura.
