# JavaScript / TypeScript

1. Preferir TypeScript strict quando o repo já usa.
2. Evitar `any`; estreitar tipos nas bordas.
3. Tratar Promise rejections; não engolir erros.
4. Respeitar ESLint/Prettier/tsconfig do projeto.
5. ESM/CJS conforme o pacote atual — sem misturar à toa.
